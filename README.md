# NCodeProcess 项目集合

本目录包含两个相互独立的 Windows 免安装项目：

- [NCodeProcess](NCodeProcess)：NC 程序扫描、校验、修改和目录处理工具。
- [NCodeProcessReportViewer](NCodeProcessReportViewer)：NC 处理报告解析和可视化查看工具。

两个项目分别包含自己的源码、测试、样例、文档、构建脚本和发布产物。构建环境均为 Anaconda `python38`，PyInstaller 版本为 `5.13.2`。

各项目的可执行文件和便携包均位于对应项目自己的 `dist` 文件夹中。
