# NCodeProcessReportViewer 技术文档

> 适用版本：1.0.0。  
> 公开范围：本文可上传 GitHub；路径只使用通用示例。  
> 权威性：本文定义查看器定位、报告兼容、字段映射、界面行为和限制；用户操作以《用户手册》为准。

## 1. 定位与边界

NCodeProcessReportViewer 是只读 Tkinter 应用，用于打开 NCodeProcess 生成的单个 JSON 报告。它不修改 NC 程序、报告 JSON、配置或报告目录，不生成日志文件，不需要网络。

查看器是报告消费端，不重新执行主工具校验；`feed_outlier`、APT、差异和运行日志均以报告内容为准。缺少新字段时按空值/兼容回退显示，不因旧报告缺少字段而崩溃。

## 2. 目录与模块

```text
NCodeProcessReportViewer/
├─ launcher.pyw
├─ ncodeprocessreportviewer/
│  └─ viewer.py                 纯展示辅助函数 + ReportViewer
├─ tests/test_report_viewer.py
├─ docs/                        四份权威文档
├─ build_portable.ps1
└─ NCodeProcessReportViewer.spec
```

运行时只依赖 Python 3.8 标准库和 Tkinter。报告读取、归一化和表格行生成尽量保持为纯函数，GUI 只负责选择和渲染。

## 3. 报告发现与读取

### 3.1 自动发现

查看器从自身所在目录及以下数据目录发现报告：

- `NCodeProcessData`；
- 兼容旧目录 `NCPostProcessData`。

支持文件名：

- `ncodeprocess-report-*.json`；
- `ncpostprocess-report-*.json`。

报告按修改时间倒序显示。用户也可以通过文件对话框打开任意 JSON。

### 3.2 最小验证

读取时要求 JSON 根节点为对象，`files` 缺失时按空数组处理，非对象文件项被过滤。读取错误通过弹窗显示，原文件保持不变。

## 4. 界面结构

默认目标窗口约 1500×800，最小约 1250×680，并根据屏幕自适应。左侧为报告列表和程序列表，右侧为：

1. 概览与可视化；
2. 文件明细；
3. APT 信息；
4. 参数统计；
5. 校验问题；
6. F 离群检测；
7. 修改与差异；
8. 运行日志；
9. 原始 JSON。

报告、程序、文件选择联动刷新；单元格悬停约 1500ms 后显示完整内容。加载前会显示“正在加载报告”，超过 5MB 时显示“大报告，加载中”；当前实现仍在主线程完成 JSON 解析和渲染，状态提示不是后台线程。

## 5. 字段映射

### 5.1 概览

读取顶层 `success`、`failed`、`skipped`、`moved`、`deleted`、`warnings`、`errors`，并展示：

- `input_dir`、`output_dir`；
- `app_version`、`generator`、`report_schema_version`；
- `elapsed_seconds`、`archive_stamp`、`backup_dir`；
- `user_confirmations`、`scan_warnings`。

图表数值通过 `chart_number` 容错，缺失或非数值回退 0。

### 5.2 文件明细

显示 `file`、`action`、`program`、`encoding`、`target`、`program_name_source`、执行状态和问题摘要。文件选择决定其它页签的过滤范围。

### 5.3 参数统计

读取 `files[].stats`：

- F/S/X/Y/Z 计数、最小值、最大值；
- G00 数量及是否发现。

缺少统计对象的文件不生成空的伪统计行。

### 5.5 F 离群检测页

独立页签，读取 `files[].feed_outlier` 并用三张表格展示：
- 文件汇总：抬刀平面、段数、离群/复核/边界错误计数与 F 分布项数；
- 检测证据：离群/复核/边界错误逐条展开（文件、行号、F 值、状态、原因、次数、最小差距、APT 参考、原始文本）；
- F 分布表：单段程序的 F 值分布（值 × 次数 × 首次行号 × 说明）。
支持“全部文件/仅检出异常”筛选与检测证据 CSV 导出（UTF-8 BOM）；底部可展开纯文本明细视图。

### 5.4 校验问题

读取 `files[].issues[]` 的文件、行号、级别、类型、原始文本和建议。error 使用红色，warning 使用橙色；支持全部/error/warning/info 筛选并可导出 UTF-8 BOM CSV。

### 5.6 修改与差异

读取 `changes` 和 `diff`。页面分为修改摘要表（文件 × 修改动作）与差异对照（左处理前/右处理后）：
删除行红色、新增行绿色、上下文灰色、diff 头蓝色；点击摘要行切换对应文件。原始 diff 只读。


### 5.7 运行日志

读取顶层 `runtime_log`，按事件名筛选并显示时间、级别、事件、消息、详情。详情区支持 traceback 和多行关键数据。`log_path` 为空时显示“日志已内嵌报告”，不尝试读取磁盘日志。

### 5.8 APT 信息

读取 `apt_summary` 或文件级 `apt_meta`、`toolpath_stats`，显示机床、后处理、CATIA APT 版本、操作、主轴、进给、冷却、装夹刀具、轨迹和抬刀统计。缺失 APT 数据时显示“当前报告无 APT 规划数据”。

## 6. F 识别数据消费

查看器不重新判断 F，只展开主工具写入的 `feed_outlier`：

- `safe_plane`：抬刀平面（程序自身最大 Z 簇）；
- `tolerance`：相对差距容差（固定 0.30）；
- `segments`：段列表（行区间 + 段内 F 计数）；
- `outliers`：离群/复核行、级别、原因、次数、最小差距、APT 状态、段号；
- `distribution`：单段程序的 F 分布表（值 × 次数 × 首次行号）；
- `boundary_errors`：F/S 硬边界；
- `apt_feeds`：配对 APT 的 FEDRAT 集合（辅助上下文）；
- `reference_count`：单段程序跨程序参照用到的常见档位数（0 = 未使用）。

展示规则：

1. 缺失 `safe_plane` 或键不全时显示“无 F 离群检测数据”，不影响其它页签；
2. 离群（warning）与复核（review）分别标注“离群告警”“复核提示”，复核不刷屏；
3. 单段程序有跨程序参照时显示参照档位数；无参照时展示 F 分布表，单次值带“请人工确认”说明；
4. APT 列只表示 `in_apt` 辅助状态，不把它改写为“合法/非法”结论；
5. 查看器不得依据 F 数值自行推断合法性，也不得把 `apt_feeds` 解释为固定合法档位。

## 7. 兼容策略

- 同时支持新旧报告文件名前缀和数据目录。
- 顶层缺失字段使用安全默认值。
- `files` 非数组、文件项非对象、日志项非对象均被过滤。
- 数字字段以 `format_number/chart_number` 容错。
- 新增字段只追加，不删除旧字段；旧字段含义改变时必须在主工具和查看器两侧同步说明。
- 查看器不依赖报告旁边存在日志文件、APT 原文件或 NC 原文件。

## 8. 测试

使用 Python 3.8 标准库 `unittest`：

```powershell
python -m unittest discover -s tests -v
```

`test_report_viewer.py` 覆盖报告发现/读取、摘要、统计、F 识别数据、APT、运行日志、问题筛选/CSV、窗口尺寸和兼容缺省。当前测试数量以 discover 输出为准；最近基线为 25 项。

## 9. 构建与安全

`build_portable.ps1` 使用与主工具相同的 Python 3.8/PyInstaller 约束：

- `-OO`、随机临时 PYZ 密钥和随机 hash seed；
- spec 的 `pyz_crypto` cipher；
- 未用标准库排除；
- `tools/upx/upx.exe` 存在时自动启用；
- EXE、便携目录、ZIP 和 `SHA256SUMS.txt`；
- 可选 Authenticode 签名。

构建产物不可逐字节复现，完整性按同次构建的 SHA256 清单验证。查看器不写入报告目录，运行时临时文件由脚本清理。

## 10. 当前限制与待办

| 优先级 | 事项 | 说明 |
|---|---|---|
| 中 | 报告列表刷新后的索引/外部删除保护 | 当前 iid 基于列表索引；刷新或外部删除后需要增加存在性校验 |
| 中 | 大报告真正后台加载 | 当前只有加载状态提示，JSON 解析和渲染仍在主线程 |
| 低 | 汇总缺失值显示“无数据” | 当前缺失汇总按 0 展示，兼容性优先 |
| 低 | 分页/增量刷新 | 中等报告可接受，全量重绘仍未分页 |
| 低 | 图表悬停数值和图表导出 | 当前仅有柱状图和问题 CSV 导出 |
| 外部验证 | Windows 7 与第三方杀软 | 必须在实际部署环境完成，不在 GitHub 文档记录本机路径 |

明确不实施：查看器不重新计算 F、不修改 NC/报告、不参与 APT 生成时间裁决、不提供规划差异大面板，除非需求重新确认。
