## 2. 项目定位

本程序是独立的 NC 后处理报告查看工具，用于解析 `NCodeProcess` 生成的 `ncodeprocess-report-*.json` 文件。查看器只读报告，不修改 NC 程序、报告或用户配置。

## 3. 文件发现

- 启动后自动扫描查看器 EXE 所在目录及其 `NCodeProcessData` 子目录。
- 自动识别文件名模式 `ncodeprocess-report-*.json`。
- 支持通过“打开报告文件”选择其他位置的 JSON 报告。
- JSON 格式错误或根节点不是对象时，应给出明确错误提示。

> 实施状态：✅ **已实现**。`discover_reports` 扫描 EXE 目录 + `NCodeProcessData`，并兼容旧版 `NCPostProcessData` 目录与 `ncpostprocess-report-*.json` 模式；`open_report` 支持任意位置 JSON；`load_report` 对根节点非对象、`files` 非数组给出明确错误。

## 4. 可视化内容

- 概览页展示输入/输出目录、开始/结束时间以及成功、失败、跳过、移动、删除、警告、错误数量。
- 使用柱状图展示处理结果和校验问题数量。
- 参数统计页展示全部文件或选中文件的 F、S、X、Y、Z 出现次数、最小值、最大值及 G00 数量。
- 校验问题页展示文件、行号、级别、类型、原始文本和建议；错误红色突出，警告橙色突出；页面下方展示 F 离群检测明细（APT 规划档位、常用档位、档位包络与离群/复核明细行，含原始文本）。
- 修改差异页展示修改说明及 unified diff；新增行绿色背景、删除行红色背景、差异定位信息蓝色显示。
- 运行日志页展示本次处理的事件时间线（时间 / 级别 / 事件 / 消息 / 详情），error 红、warning 橙突出，支持按事件类型筛选；日志完整内嵌报告（WP-C6；WP-R4 起不再生成磁盘日志文件）。
- APT 信息页展示 APT 规划与轨迹：全部文件显示全局摘要（机床/转速/刀具/操作/刀具使用/轨迹汇总），选中文件显示该程序 APT 的规划详情（含操作级进给与主轴、XYZ 行程、抬刀次数）；刀具按规格+种类合并并给出具体规格，操作清单按程序分别列出（WP-A5）。
- 概览页元信息展示工具版本、报告来源、报告结构版本、处理耗时、APTSOURCE 归档时间戳、用户确认项与扫描警告；文件明细表展示目标路径与程序名来源标记（报告内容规范第 12 节）。
- 原始 JSON 页提供完整数据核对。

> 实施状态：✅ **已实现**。Notebook 八页（概览与可视化 / 文件明细 / APT 信息 / 参数统计 / 校验问题 / 修改与差异 / 运行日志 / 原始 JSON）；概览含 7 项汇总、元信息（含第 12 节增强字段）与双柱状图（Tk Canvas 自绘）；统计支持「全部文件 / 选中文件」切换；问题按 error/warning 红/橙着色；差异页红删绿增、`@@`/头部蓝色；APT 信息页消费 `apt_meta`/`toolpath_stats`/`apt_summary`（WP-A5）；运行日志页含事件筛选与 `log_path` 提示（WP-C6）；文件明细表含「目标」列与来源标记；原始 JSON 只读缩进展示。

## 5. 界面要求

- 默认窗口适合 1920×1080 分辨率，约 1290×720 不全屏；默认状态所有表头完整可见，无需拖动，最小窗口尺寸为 1160×640。
- 报告列表与逐文件明细分栏展示。
- 所有长表格和文本区域提供纵向、横向滚动条。
- 表格单元格内容被列宽截断时，鼠标悬停自动浮窗显示完整内容。
- 选中报告或文件后立即刷新相关页面，不重复读取文件。

> 实施状态：✅ **已实现**。`window_geometry_for_screen` 按屏幕收缩（1366×768 → 1206×640，最小 1160×640）；左栏报告列表 + 文件明细、右栏 Notebook 分页；全部表格/文本区带纵横滚动条；`_on_report_selected`/`_on_file_selected` 选中即刷新；5 张表格（报告列表/文件明细/参数统计/校验问题/运行日志）均支持悬停浮窗显示完整内容。

## 6. 发布要求

- 使用 Python 3.8 和 PyInstaller 5.13.2 打包。
- 提供单文件 `NCodeProcessReportViewer.exe` 和便携 ZIP。

> 实施状态：✅ **已实现**。`build_portable.ps1`（`-CondaEnvironment <Python 3.8 环境名>`）产出单文件 EXE、便携目录与 ZIP；发布构建启用随机密钥字节码加密、`-OO` 优化、运行时反调试、调试模块裁剪与 SHA-256 完整性记录（详见 `SECURITY.md`）。
