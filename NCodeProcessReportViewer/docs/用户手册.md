# NC 处理报告查看器用户手册

> 适用程序：NCodeProcessReportViewer 1.0.0。  
> 本手册可公开发布；示例目录均为通用内容。  

## 1. 程序用途

NCodeProcessReportViewer 用于**只读查看** NCodeProcess 生成的 JSON 报告（`ncodeprocess-report-*.json`）：处理汇总、文件状态、APT 信息、参数统计、校验问题、F 离群证据、修改差异、运行日志与原始 JSON。

查看器**不会**修改 NC 程序或报告文件，也不会重新判断校验结果——所有内容以报告为准。

## 2. 部署与启动

1. 将 `NCodeProcessReportViewer.exe` 放到 NC 处理目录；
2. 确认报告位于当前目录或 `NCodeProcessData`（兼容旧版 `NCPostProcessData` 与 `ncpostprocess-report-*.json`）；
3. 双击 EXE。

程序自动发现报告（按修改时间倒序）。也可以点击"打开报告文件"直接选择其他目录的 JSON。

默认窗口约 1500×800（最小 1250×680），按屏幕自适应，居中显示。**最低完整界面目标是 Windows 7、1366×768、100% DPI**。

排故：

| 现象 | 处理 |
|---|---|
| 没有发现报告 | 点"重新扫描报告"；确认文件名与目录规则；或直接"打开报告文件" |
| 双击 EXE 无反应 | 确认 Windows 7 及以上；校验 EXE 完整性（`SHA256SUMS.txt`） |

## 3. 界面布局总览


- **顶部工具栏**：打开报告文件 / 重新扫描报告 / 当前报告状态标签；
- **左侧**（固定约 440px）：报告列表（时间、报告文件）+ 程序列表（程序、校验情况）；
- **右侧**：九个页签——概览与可视化、文件明细、APT 信息、参数统计、校验问题、F 离群检测、修改与差异、运行日志、原始 JSON。

选择报告、程序或文件后，相关页面立即联动刷新。表格内容被截断时，悬停单元格约 1.5 秒弹出完整内容浮窗；长表格支持横纵滚动。

## 4. 顶部工具栏

| 控件 | 说明与操作 | 排故 |
|---|---|---|
| 打开报告文件 | 弹文件选择框，选择任意位置的 JSON 报告 | 选择后报"报告读取失败"：文件不是完整 JSON / 根节点不是对象 / `files` 不是数组 |
| 重新扫描报告 | 重新发现报告并刷新左侧列表，自动加载最新报告 | 外部删除报告后刷新不再报错（自动跳过不可读文件）；列表为空时见 §2 排故 |
| 报告状态标签 | 显示"未加载报告" / "当前报告：路径"；加载中显示"正在加载报告……"，超 5MB 显示"报告较大，正在加载" | 大报告加载期间界面可能短暂等待——当前版本为主线程同步解析（已知限制），不要连续点击多个报告 |

## 5. 左侧栏

### 5.1 报告列表

列：时间 / 报告文件。按修改时间倒序。单击报告 → 加载并刷新全部页面。

排故：报告多且最新在底部——列表按时间倒序，最新在上；看不到想要的报告用"打开报告文件"。

### 5.2 程序列表

列：程序 / 校验。聚合行包括：

- **全部程序**：报告全局内容（默认选中）；
- 各程序名：只显示该程序相关文件；
- **未配对文件**：无法归入程序的项目。

校验列显示"N 错 / M 警"或"无问题"。单击程序 → 文件明细按该程序筛选。

## 6. 概览与可视化


页面内容：

1. **结果统计卡片**（7 张）：成功、失败、跳过、移动、删除、警告、错误——处理执行计数；
2. **元信息**（多行文本）：输入/输出目录、开始/完成时间、工具版本、报告来源、报告结构版本、处理耗时、APTSOURCE 归档时间戳、备份目录、用户确认项、扫描警告、运行环境（平台/Python 版本/位数）；
3. **处理结果可视化**：文件处理结果柱状图（成功/失败/跳过/移动/删除，绿/红/灰/蓝/紫）+ 校验问题柱状图（错误/警告，红/橙）；无数据显示"暂无数据"；
4. **处理配置**表格（配置项/值）：报告生成时的实际配置快照（29 项：文件编码、递归扫描、保存 APTSOURCE、覆盖、扩展名、G00 级别、M03、F/S 上下限、换行、必填 MSG、辅助顺序、多 S 警告、结束标记、M06、S 转速、大小/数量上限、抬刀高度阈值、备份询问等）；布尔显示"是/否"，列表顿号连接；无快照显示"当前报告无配置快照"。

排故：数字与预期不同——汇总来自报告生成时的执行结果，不是查看器重新扫描当前目录；旧报告缺字段按 0/空显示（兼容回退，不崩溃）。

## 7. 文件明细


表格列：**程序/文件**（程序名+来源标记）、**动作**、**校验**（N 错/M 警）、**目标**、**失败原因**。首行为"全部文件/汇总"。

常见动作/状态：

- `success`：执行成功；
- `failed`：执行失败——"失败原因"列显示具体原因（如 `io: 无法写入文件`）；
- `skipped/review`：跳过或需复核；
- `moved/deleted`：归档或删除；
- `planned`：报告可能来自预览或兼容版本，尚无执行状态。

单击某行 → APT、参数统计、校验问题、F 离群、修改差异、运行日志页签切换到该文件。

排故：查看器只显示报告记录，**不能从这里重新执行处理**。

## 8. APT 信息


两列表格（项目/APT 规划值）：

- **未选中文件（全部程序）**：报告级摘要——机床、主轴转速、备刀/装夹刀具、操作列表、刀具使用程序数、GOTO/圆弧/抬刀汇总；
- **选中单文件**：后处理表、CATIA APT 版本、生成时间、程序名、操作级进给/主轴、冷却液、刀具规格（按规格+种类合并）、XYZ 行程、GOTO 点数、圆弧数、抬刀次数、抬刀平面。

排故：页面为空/显示"当前报告无 APT 规划数据"——报告没有 APT 字段（旧报告或未配对 APT），不影响其他页签。

## 9. 参数统计


列：文件/程序、参数、次数、最小值、最大值、G00。参数为 F/S/X/Y/Z 逐行 + 每文件 G00 行（发现/未发现）。选中单文件时仅该文件行。

统计来自主工具处理时结果；查看器**不重新读取 NC 文件**——即使原 NC 已被移动，报告仍可查看。

## 10. 校验问题


- **级别筛选**下拉框：全部 / error / warning / info；
- **导出问题 CSV**：保存当前报告全部问题为 CSV（UTF-8 BOM，可直接用表格软件打开；**以报告完整清单为准，不受筛选影响**）；
- 问题表列：文件、行、级别、类型、原始文本、建议。error 红、warning 橙。

排故：导出报"无问题"——报告确实无问题记录；筛选后行变少——筛选只影响显示，不影响导出。

## 11. F 离群检测


独立页签，展示主工具写入的 F 检测结果（不重新计算）：

- **文件筛选**：全部文件 / 仅检出异常；
- **导出证据 CSV**：检测证据导出（UTF-8 BOM）；
- **文件汇总**表：抬刀平面、段数、离群告警/复核提示/边界错误条数、F 分布项数；
- 子页签①**检测证据**：文件、行、F 值、状态（离群告警/复核提示/边界错误）、原因、次数、最小差距、APT 参考、原始文本；
- 子页签②**F 分布表**：单段程序人工判定用（值×次数×首次行号×说明）；
- **显示文本明细**勾选框：展开/收起纯文本证据视图（便于复制）。

状态与原因速查：

| 状态 | 含义 |
|---|---|
| 离群告警 | 该 F 全程序罕见且与其他段所有值差距 >60% |
| 复核提示 | 差距 30%~60%，需人工确认 |
| 边界错误 | F0/负值或超 F/S 上下限 |
| APT 参考 | "在 APT"= 接近报告记录的 FEDRAT；"不在 APT"= 无匹配参考；"无 APT 参考"= 报告无 APT 数据 |

排故：页面为空——报告无 F 离群字段（旧报告），不影响其他页签。

## 12. 修改与差异


- **修改摘要**表：文件 + 修改内容（changes 前 8 项，超 8 项加"…"；并入"换刀跳过：原因""重复：采用 文件"）；仅有重复裁决而无改动的文件也会列出；
- **差异对照**：左"处理前"、右"处理后"，四窗格同步滚动（行号栏×2 + 文本区×2）。删除行红、新增行绿、上下文灰、@@/文件头蓝粗；点击摘要表行切换对应文件差异。

差异来自报告，**不要求当前目录仍保留原 NC 文件**。

## 13. 运行日志


- **事件筛选**下拉框：按事件名过滤（默认"全部"，选项来自报告内事件集合）；
- 日志表：时间、级别、事件、消息、详情；error 红、warning 橙；
- **选中事件详情**区：点击日志行，下方展示该事件完整详情（含多行 traceback 与关键运行数据）；
- 底部说明：日志已完整内嵌报告（`runtime_log`），不再生成磁盘日志文件；`log_path` 为空属正常。

## 14. 原始 JSON


报告全文只读展示（格式化 JSON）。用于核对全部字段。旧报告可能缺少 APT、F 分段、配置快照或运行日志字段，查看器使用兼容空值。

## 15. 常见问题

| 问题 | 处理 |
|---|---|
| 没有发现报告 | "重新扫描报告"；确认文件名/目录规则；"打开报告文件"直接选择 |
| 报告读取失败 | 文件必须是完整 JSON，根节点是对象，`files` 是数组。不要用文本编辑器保存成截断/非 JSON 内容 |
| 大报告加载时窗口短暂不响应 | 当前版本同步解析（加载提示非后台任务）。等待完成，不要连续点击多个报告 |
| 数量与预期不同 | 汇总来自报告生成时的执行结果，不是查看器重新扫描当前目录 |
| APT/F 页面为空 | 旧报告或未配对 APT 的报告可能缺这些字段，不影响其他页签 |
| 报告中显示真实文件路径 | 路径来自报告本身。对外分享报告前应按组织要求脱敏；查看器不会自动修改或隐藏报告字段 |
| 表格内容看不全 | 悬停单元格约 1.5 秒弹完整内容浮窗；表格支持横纵滚动 |

## 16. 安全与完整性

1. 查看器只读，不需要管理员权限；
2. 只打开可信来源的 JSON；超大或恶意构造文件可能占用较多内存；
3. 使用发布包内 `SHA256SUMS.txt` 核对 EXE；
4. 构建使用随机字节码加密密钥，同一源码的不同 EXE 哈希不同是正常现象。
