# NC 处理报告查看器用户手册

> 适用程序：NCodeProcessReportViewer 1.0.0。  
> 本手册可公开发布，示例目录均为通用内容。

## 1. 程序用途

NCodeProcessReportViewer 用于只读查看 NCodeProcess 生成的 JSON 报告。它可以查看处理汇总、文件状态、APT 信息、参数统计、校验问题、F 结构证据、修改差异、运行日志和原始 JSON。

查看器不会修改 NC 程序或报告文件，也不会重新判断校验结果。

## 2. 部署与启动

推荐方式：

1. 将 `NCodeProcessReportViewer.exe` 放到 NC 处理目录；
2. 确认报告位于当前目录或 `NCodeProcessData`；
3. 双击 EXE。

查看器自动识别：

- `ncodeprocess-report-*.json`；
- 旧版 `ncpostprocess-report-*.json`；
- 当前目录、`NCodeProcessData`、旧版 `NCPostProcessData`。

程序使用自定义图标（EXE 文件图标与运行窗口标题栏/任务栏图标一致），与 NC 程序处理工具同系列设计。

也可以点击“打开报告文件”，直接选择其他目录的 JSON。

## 3. 界面布局

左侧：

- 报告列表：按修改时间倒序；
- 程序列表：全部程序、单个程序和未配对文件。

右侧八个页面：

1. 概览与可视化；
2. 文件明细；
3. APT 信息；
4. 参数统计；
5. 校验问题；
6. F 离群检测；
7. 修改与差异；
8. 运行日志；
9. 原始 JSON。

选择报告、程序或文件后，相关页面立即刷新。表格内容被截断时，把鼠标停留在单元格约 1.5 秒即可查看全文。

## 4. 查看报告

### 4.1 选择报告

点击左侧报告。加载时顶部显示状态；报告超过 5MB 时会提示“大报告，加载中”。当前版本加载期间界面可能短暂等待，这是已知限制。

### 4.2 选择程序和文件

- “全部程序”：显示报告全局内容；
- 选择程序：只显示该程序相关文件；
- “未配对文件”：查看未能归入程序的项目；
- 文件明细中选择单个文件：APT、统计、问题和差异页切换到该文件。

## 5. 概览与可视化

概览显示：

- 成功、失败、跳过、移动、删除；
- 警告和错误数量；
- 输入/输出目录和处理时间；
- 工具版本、报告来源、结构版本；
- 备份目录、归档时间戳；
- 用户确认和扫描警告；
- 运行环境（平台 / Python 版本 / 位数）；
- 处理配置快照（文件编码、递归、覆盖、扩展名、F/S 上下限、必填字段等全部处理配置）。

柱状图只用于快速比较数量。报告字段缺失或不是数字时按 0 绘制，避免旧报告或异常报告导致崩溃。

## 6. 文件明细

文件表显示源文件、目标文件、程序名、动作、编码、状态、程序名来源和问题摘要；执行失败的文件在“失败原因”列显示具体原因（如 `io: 无法写入文件`）。

常见状态：

- success：执行成功；
- failed：执行失败；
- skipped/review：跳过或需要复核；
- moved/deleted：归档或删除；
- planned：报告可能来自预览或兼容版本，尚无执行状态。

查看器只显示报告记录，不能从这里重新执行处理。

## 7. APT 信息

选择“全部程序”时显示报告级摘要：

- 机床；
- 主轴转速；
- 备刀/装夹刀具；
- 操作列表；
- 刀具使用程序数；
- GOTO、圆弧和抬刀汇总。

选择单个文件时显示：

- 后处理表、CATIA APT 版本、生成时间、程序名；
- 操作级进给和主轴；
- 冷却液和刀具规格；
- XYZ 行程、GOTO 点数、圆弧、抬刀和退刀平面。

报告没有 APT 数据时显示空状态，不表示报告损坏。

## 8. 参数统计

参数表显示每个文件的 F、S、X、Y、Z：

- 出现次数；
- 最小值；
- 最大值；
- G00 数量和是否发现。

统计来自主工具处理时的结果。查看器不会重新读取 NC 文件，因此即使原 NC 已被移动，报告仍可查看。

## 9. 校验问题

### 9.1 颜色和级别

- error：红色，通常表示该文件未安全写入或必须修正；
- warning：橙色，需要人工确认；
- info：普通提示或复核信息。

可以选择“全部”“error”“warning”“info”筛选。

### 9.2 导出问题 CSV

点击“导出问题 CSV”，保存当前报告的全部问题。文件使用 UTF-8 BOM，可直接用常见表格软件打开。

导出 CSV 不会修改 JSON，也不会只导出当前筛选结果；它以报告中的完整问题清单为准。

## 10. F 离群检测

独立页签，把 F 抬刀平面分段检测从校验问题页拆出，以表格形式展示：

- 文件汇总：每个程序的抬刀平面、段数、离群告警/复核提示/边界错误条数与 F 分布项数；
- 检测证据：离群/复核/边界错误逐条列出文件、行号、F 值、状态、原因、全程次数、最小差距与 APT 参考；
- F 分布表：单段程序人工判定用的 F 值分布（值 × 次数 × 首次行号）。

工具栏可切换“全部文件 / 仅检出异常”筛选，并可导出检测证据 CSV（UTF-8 BOM）。
底部勾选“显示文本明细”可展开原来的纯文本证据视图。

## 11. F 异常与证据

页面会展开主工具写入的 F 识别结果，不会重新计算。

### 10.1 分段统计

显示抬刀平面、段数和容差（固定 30%）。段由程序自身最大 Z 簇切分，一段 = 下刀 → 加工 → 回到抬刀平面。

### 10.2 离群/复核

离群（警告）表示该 F 全程序罕见且与其他段所有值差距超过 60%；复核表示差距在 30%~60% 之间，需要人工确认。条目显示行号、F、次数、最小差距和原始行。

### 10.3 单段程序

程序只有一段时，主工具会与同目录其它程序的常见档位对比（查看器显示参照档位数）；目录中没有参照时展示 F 分布表（值 × 次数 × 首次行号），单次值带“仅出现一次，请人工确认”说明。

### 10.4 APT 状态

“在 APT”表示该 F 与报告记录的 APT `FEDRAT` 参考接近；“不在 APT”只表示没有匹配参考；报告没有 APT 数据时显示“无 APT 参考”。APT 是辅助信息，不等于最终合法/非法结论。

## 12. 修改与差异

页面分为两部分：

- 修改摘要表：列出每个被处理文件的修改动作（插入头部字段、更新刀具、补写 M03、重命名等），并附自动换刀跳过原因与重复目标裁决关系（“换刀跳过：…”“重复：采用 …”）；仅有重复裁决而无改动的文件也会列出；
- 差异对照：左栏为处理前、右栏为处理后，删除行红色、新增行绿色、上下文灰色，蓝色为定位/修改块位置；
  点击摘要表中的文件即可切换查看对应差异。

差异来自报告，不要求当前目录仍保留原 NC 文件。


## 13. 运行日志

运行日志完整内嵌在 JSON 的 `runtime_log` 中。可以按事件类型筛选，并在下方查看完整详情，例如 traceback、扫描数量、备份结果和单文件处理摘要。

当前版本不生成独立磁盘日志，`log_path` 通常为空。看到“日志已内嵌本报告”属于正常状态。

## 14. 原始 JSON

原始 JSON 页面用于核对全部字段。文本只读。旧报告可能缺少 APT、F 分段、配置快照或运行日志字段，查看器会使用兼容空值。

## 15. 常见问题

### 没有发现报告

点击“重新扫描报告”，确认文件名和目录符合规则，或直接点击“打开报告文件”。

### 报告读取失败

确认文件是完整 JSON，根节点是对象，`files` 是数组。不要用文本编辑器保存成截断或非 JSON 内容。

### 大报告加载时窗口短暂不响应

当前版本仍同步解析和渲染，加载提示并非后台任务。等待完成，不要连续点击多个报告。

### 数量与预期不同

查看“文件明细”和原始 JSON。汇总来自报告生成时的执行结果，不是查看器重新扫描当前目录得到的数量。

### APT/F 页面为空

旧报告或未配对 APT 的报告可能没有这些字段。这不影响文件、问题、差异和日志等其它内容。

### 报告中显示真实文件路径

路径来自报告本身。对外分享报告前应按组织要求脱敏；查看器不会自动修改或隐藏报告字段。

## 16. 安全与完整性

1. 查看器只读，不需要管理员权限。
2. 只打开可信来源的 JSON；超大或恶意构造文件可能占用较多内存。
3. 使用发布包内 `SHA256SUMS.txt` 核对 EXE。
4. 构建使用随机字节码加密密钥，同一源码的不同 EXE 哈希不同是正常现象。
